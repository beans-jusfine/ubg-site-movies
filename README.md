# NERO Movies

A lightweight, dark NERO-branded movie discovery interface.

## Integration status
- Cinevo is linked as an external destination only.
- This project does not scrape Cinevo, copy its catalog, or frame its pages.
- Catalog/API and embedded playback integration require written permission and provider documentation.
- Watchlist and Continue Watching are stored locally in the current browser.

## Run
Open `index.html` in a browser or deploy the repository as a static site.
