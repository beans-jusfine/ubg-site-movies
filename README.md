# NERO Movies

A NERO-branded movie and TV discovery app powered by The Movie Database (TMDB).

## Features
- Trending, popular, and top-rated movies and TV shows.
- Multi-search across movies and TV shows.
- Details including synopsis, genres, runtime/seasons, ratings, and cast.
- TMDB watch-provider availability where regional data exists.
- On-device Watchlist and Continue Watching history.

## TMDB setup
1. Sign in to TMDB and request an API key from account settings.
2. Open NERO Movies and select the gear icon.
3. Paste your TMDB API key and save.
4. The key is stored in that browser's localStorage. It is not included in this repository or sent to a NERO backend.

Browser API keys are visible to that browser's user. Use a key you control and follow TMDB's API terms and attribution requirements.

## Data and attribution
This app uses TMDB APIs and image assets. NERO Movies is not endorsed or certified by TMDB. TMDB data availability and watch-provider listings vary by region.

## Run
Open index.html in a browser or deploy the repository as a static site.
